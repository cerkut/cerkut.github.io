  3. Audio Propagation and Occlusion in a Puzzle Game
    Christian Kirkebjerg Thorup, Vahid Haidari, Oskar Møller Nielsen, and 2 more authors
    2026
    Abs Bib Website

    This report aims to explore the possibility of using audio propagation and occlusion as the main mechanics in a puzzle game. Audio is typically an important factor in creating immersion in a video game. Therefore, testing if it can also be used as a leading factor in creating flow, could be interesting for games moving forward. The game, in which this was tested, was developed iteratively in Unity 6, using FMOD in combination with raycasting, to create the audio system. The game included multiple levels, in an attempt to balance the difficulty with the acquired skills of the players. Multiple methods were used to test for flow in each iteration of the game, with the final iteration using the Flow Observation Grid and the Game Experience Questionnaire. The methods found a general agreement that flow had been provided by audio occlusion and propagation, meaning it is probable that they can be a meaningful mechanics in future puzzle games.

  5. Acoustic Drum-Kit Source Separation with Inter-Limb Onset Detection for Timing Analysis and Training
    Baldur Kampmann
    2020
    Abs Bib Website

    This paper focuses on acoustic drum-kit source separation and onset detection for analysis of timing performance. By taking the human motor and sensory system into account, a set of requirements are specified to guide the design and implementation of a prototype learning tool for use by drummers to improve their timing precision. The prototype is evaluated from a system and user perspective and lastly the evaluation results and potential improvements are discussed.
